# Basic Node.js Web Server

A simple multi-page website served using Node.js's built-in HTTP module. This project was created as a first exercise in working with Node.js and its native modules.

## Features

- Serves multiple HTML pages based on the requested URL.
- Serves static assets such as CSS.
- Handles unknown routes with a custom 404 page.
- Uses HTTP status codes to handle different responses.

## Technologies

- Node.js
- JavaScript
- HTML
- CSS

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:

   git clone git@github.com:Misubold22/basic-informational-site.git

2. Navigate to the project directory:

3. Start the server:

   node server.js

4. Open your browser and navigate to:

   http://localhost:3000
